BackupFlow Help

BackupFlow backs up your iPhone photos, videos and files to your own server: a NAS, a home server or your personal cloud. No subscription and no third-party cloud.

What you need

  • A server that supports FTP, SFTP or WebDAV. Most NAS devices (such as Synology or QNAP) and personal clouds like Nextcloud support at least one of these.
  • The server address, a username and a password.
  • If the server is on your home network, tap Allow when iOS asks for local network access.

Set up your first backup

  1. On the Backup Hub, tap Add next to Saved servers.
  2. Choose the connection type (FTP, SFTP or WebDAV) and enter the server address, username and password.
  3. Tap Test Connection to make sure everything is correct.
  4. Under Source, choose Photo Library (photos, videos or both) or tap Select Folder to pick a folder from the Files app.
  5. Enter a Destination Folder on the server, or tap Browse remote folder to pick one.
  6. Choose a schedule and tap Save Task. BackupFlow offers to start the first backup right away.

After the first backup, only new or changed files are sent, so later backups are much faster.

Automatic backups

Choose how often the backup runs: Manual, Every few hours, Daily, Weekly or Monthly.

You can also decide when a backup is allowed to run:

  • Require Wi-Fi: never uses mobile data.
  • Require external power: runs only while the iPhone is charging.
  • Use allowed time window: for example, only at night.
  • Minimum Battery Level (in Settings › Battery Settings): skips backups when the battery is low.

If a condition isn't met, the backup waits and starts once it is. To stop a task for a while, open it and tap Pause Scheduling.

Deleted files

Under Deletion policy, choose what happens on the server when you delete something on your iPhone:

Mirror (default)
The server stays an exact copy of the source. Files you delete on your iPhone are deleted from the server too.
Append-only
Nothing is ever deleted from the server.
Archive delete
Nothing is deleted. Removed files are moved to a dated .backupflow_archive folder on the server.

Planning to free up space on your iPhone after backing up? Switch to Append-only or Archive delete before you delete anything.

Backing up in the background

iOS decides when apps can work in the background, so a scheduled backup may not start at exactly the chosen minute. When it's time, BackupFlow starts the backup or sends a notification. Tap Start Now to begin.

If iOS stops a backup before it finishes, open BackupFlow and it continues. Files that were already sent are skipped.

For a large first backup, keep your iPhone on Wi-Fi and connected to power.

Backup history

Your latest backups appear on the Backup Hub. Tap See all for the full Backup History. Each entry shows how many files were sent, the total size and how long it took. You can also share it as a report.

To choose how long history is kept, go to Settings › History Retention.

Extra protection

  • Verify uploads: checks that every file arrived on the server intact.
  • Download iCloud items if needed: also backs up photos and videos that are stored only in iCloud.
  • SFTP: BackupFlow remembers your server the first time you connect and warns you if its identity changes.

Troubleshooting

I can't connect to my server.
Check the address, port, username and password. Usual ports: FTP 21, SFTP 22, WebDAV 443. For a server at home, make sure your iPhone is on the same Wi-Fi network and local network access is on in iPhone Settings › Privacy & Security › Local Network.
A scheduled backup didn't run.
Check the task's conditions (Wi-Fi, power, time window, battery) and make sure notifications are allowed for BackupFlow. Open the app to start a backup that is waiting.
Some photos are missing.
Turn on Download iCloud items if needed. With iCloud Photos, many originals are kept only in iCloud.
Files disappeared from my server.
The task is probably set to Mirror. Switch it to Append-only or Archive delete.
I see an SFTP security warning.
The server's identity has changed. This is expected if the server was reinstalled or replaced. Otherwise, check with whoever manages the server before continuing.

Privacy

Your files go straight from your iPhone to your own server. BackupFlow has no servers of its own, never sees your files and collects no data. Passwords are stored securely on your device.

Settings › Reset All Data removes all tasks, history and saved passwords from this device. Files on your servers are not touched.

Need help?

Go to Settings › Contact Support to send us an email. Your app version and device model are added automatically.
